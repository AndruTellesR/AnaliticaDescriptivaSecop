# Documento 07 — Random Forest

**Notebook**: `notebooks/07_modelo_rf.ipynb`
**Familia**: Ensamble por bagging
**Target optimizado**: `tuvo_atraso`
**Modelo persistido**: `data/modelos/rf.pkl`

## Descripción del algoritmo

Ensamble de árboles entrenados sobre muestras bootstrap y subsets aleatorios de features. Captura interacciones no-lineales. No requiere escalado.

## Configuración

- `RandomizedSearchCV` con `n_iter = 40`
- `StratifiedKFold(5)`
- Scoring: `roc_auc`
- `random_state = 42`
