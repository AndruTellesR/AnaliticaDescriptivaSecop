# 02 — Anexos técnicos del informe final

Esta carpeta contiene los tres anexos que acompañan al informe final del
trabajo dirigido. Profundizan aspectos específicos que no caben en el cuerpo
principal del documento.

## Contenido

| Archivo | Profundiza |
|---------|------------|
| `ANEXO-A-fuentes-y-variables.md` | Inventario completo de fuentes integradas, esquema relacional, descripción detallada de las 152 variables del modelo final y las 14 variables excluidas por leakage |
| `ANEXO-B-detalle-modelo.md` | Hiperparámetros óptimos de los ocho algoritmos del zoológico, métricas completas y justificaciones técnicas detalladas de cada decisión |
| `ANEXO-C-repositorio.md` | Estructura del repositorio, dependencias, variables de entorno, pasos para reproducir los resultados y lista de servicios externos utilizados |

## Cómo se referencian desde el informe principal

El informe final hace referencias cruzadas a estos anexos en los siguientes
puntos:

- Capítulo 1 (Datos) → Anexo A para el detalle del esquema relacional y el
  diccionario completo de variables.
- Capítulo 3 (Modelo) → Anexo B para los hiperparámetros y justificaciones
  detalladas.
- Conclusiones → Anexo C para los pasos de reproducibilidad.
